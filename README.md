# agent-cad

エージェント駆動で製造品質のCADモデルを開発するためのリポジトリ。
カーネルは OpenCascade（build123d / OCP）、出力は STEP AP242。

## 構成

- `agent_cad/parts/` パラメトリック部品（寸法・材質・質量目標を引数で変更可能）
  - `stem.py` 自転車ステム（2ボルト・コラムクランプ、4ボルト・フェイスプレート）
- `agent_cad/fea/` 線形静解析（gmsh + scikit-fem, P2四面体）
- `agent_cad/step_io.py` STEP AP242 入出力（製品構成・部品名・色・材質/密度・幾何検証プロパティ付き）
- `agent_cad/verify/step_check.py` STEP受け渡しの自己完結チェック（下記）
- `agent_cad/verify/stem_verify.py` 設計検証ループ（肉厚・干渉・ねじ掛かり・質量・強度、下記）
- `agent_cad/materials.py` 強度計算用の材料特性
- `agent_cad/process/forging.py` 型鍛造品（抜き勾配・取り代・バリ）と上下型の生成
- `agent_cad/verify/forging_check.py` 鍛造品・金型のチェック（取り代・抜き勾配・アンダーカット・型の干渉・荷重）
- `agent_cad/drawing/` JIS図面（第三角法、断面・矢視、寸法・はめあい・幾何公差・表面粗さ、表題欄）をPDF/DXFで出力
- `agent_cad/standards/jis.py` JIS B 0405 普通公差、JIS B 0401 はめあい表
- `agent_cad/parts/stem_drawing.py` ステム本体・フェイスプレートの図面定義
- `agent_cad/parts/housing.py`, `housing_drawing.py` 樹脂射出成形ハウジングとその図面
- `agent_cad/process/molding.py`, `agent_cad/verify/molding_check.py` 射出成形金型（スライド・冷却・突出し）とそのチェック
- `agent_cad/parts/handlebar.py`, `handlebar_drawing.py` ロードドロップハンドルとその図面
- `agent_cad/process/tube_bending.py`, `agent_cad/verify/tube_check.py` 管のスエージング・回転引き曲げの工程と治工具、そのチェック
- `agent_cad/verify/handlebar_verify.py`, `agent_cad/fea/beam.py`, `bar_fea.py` ハンドルの強度検証（梁FEAとソリッドFEA）
- `agent_cad/fastener.py`, `agent_cad/verify/fastener_check.py` ボルト締結計算（VDI 2230 簡易法・JIS B 1083）と各部品の継手
- `agent_cad/fea/convergence.py`, `agent_cad/verify/mesh_study.py` メッシュ品質とメッシュ収束（Richardson 外挿・GCI）
- `agent_cad/report.py` A4 計算書 PDF（締結計算書・メッシュ収束解析報告書）
- `agent_cad/render.py` 簡易レンダリング（matplotlib）
- `scripts/` 生成スクリプト（出力は `out/`）

## 使い方

```sh
pip install -r requirements.txt
python -m scripts.make_stem          # STEP / レポート / 画像を out/ に出力
python -m scripts.verify_stem        # 設計検証ループ（不合格なら終了コード1）
python -m scripts.make_forging       # 鍛造品・鍛造型の STEP / レポート / 画像を out/ に出力
python -m scripts.make_diecast       # ダイカスト品・ダイカスト型
python -m scripts.make_molding       # 樹脂ハウジング・射出成形金型・図面
python -m scripts.make_handlebar     # ドロップハンドル・スエージ/曲げ型・図面
python -m scripts.fastener_report    # 締結計算書（PDF/JSON）を out/fastener/ に出力
python -m scripts.mesh_study         # メッシュ収束解析（約30分）を out/mesh/ に出力
python -m scripts.verify_stem --set length=120 --set material=A7075-T6 --json out/v.json
```

## STEP受け渡しチェック（CATIA読込テストの代替）

CATIA実機での読込確認ができるまで、書き出したSTEPを以下で自動検証する。`make_stem` は
各STEPに対して実行し、結果を `out/*_report.json` の `step_exchange` に入れる。

| 区分 | 内容 |
|---|---|
| text | OpenCascadeを使わない独立パース：スキーマがAP242、長さ単位mm、全参照が解決、ソリッド数 |
| struct | 製品構成（アセンブリ名、部品名）と色が往復で保たれる |
| topo | 各部品が1つの有効な閉ソリッド（自由エッジ0） |
| geom | 体積・表面積・重心が元形状と一致し、ファイル内の幾何検証プロパティとも一致。慣性テンソル・外形範囲・表面上の点の照合で向きや配置のずれも検出 |
| mesh | 独立した三角形分割の体積がB-rep体積と0.5%以内（面欠落の検出） |
| tol | 最大トレランス ≤ 0.01 mm、最短エッジ ≥ 0.01 mm（CATIAの分解能0.001 mmに対し余裕） |
| rewrite | 読み込んだモデルを書き直して再読込しても質量特性が不変 |

幾何検証プロパティ（体積・面積・重心）はAP242の仕組みで、CATIA側でも読込時に照合できる。
材質名と密度もSTEPに書き込む。

```sh
python -m pytest -q tests   # 正常ファイルの合格と、面欠落・検証値改ざん・単位違いの検出を確認
```

## 図面（JIS）

`make_stem` は部品ごとに `out/<名前>_<部品>_drawing.pdf` と `.dxf` を出力する。

- 第三角法、A3、尺度は1:1（小物は2:1）。収まらなければ用紙をA2にし、それでも収まらなければ尺度を1:2、1:5と下げる（本体）。フェイスプレートは尺度を下げてからA2にする
- 図番は部品パラメータのハッシュから付ける（`AC-STEM-xxxxxx-01`）。寸法・角度・材料が違う品番は必ず別図番になる
- PDFには日本語フォントが必要（IPAゴシック、Noto Sans CJK JPなど。例: `apt-get install fonts-ipafont-gothic`）。見つからないときは文字化けしたPDFを出さずにエラーで止まる
- 寸法値はパラメータではなくB-repから測った値を記入する（穴径、軸間距離、ボルトピッチなど）
- はめあい公差はJIS B 0401の表から計算する（クランプ穴はF8）。普通公差はJIS B 0405-m、幾何公差の普通公差はJIS B 0419-K
- 表面粗さはJIS B 0031の記号で記入する（一括指示はRa 3.2、クランプ穴と合わせ面はRa 1.6）
- 材料はJIS H 4140の鍛造品記号、表面処理はJIS H 8601

図面チェック（`agent_cad/drawing/check.py`）：

- 測った寸法と設計意図（パラメータ）が0.005以内で一致すること
- はめあいの許容差が表の値と一致すること
- 表題欄・投影法・普通公差・一括粗さの記載があり、クランプ穴と合わせ面に個別の粗さ記号があること
- 必要な形状（穴・ねじ・ザグリ・断面）がモデルにあり、ボルト穴とザグリが4隅の位置にあること
- 文字どうし、および文字と外形線が重ならず、文字が枠内に収まること

## 設計検証ループ

`verify(StemParams(...))` はパラメータからモデルを作り直し、全ルールを判定する。各ルールは測定値・限界値・根拠を持つので、不合格のときに何を変えればよいかがわかる。

| ルール | 判定 | 根拠 |
|---|---|---|
| geometry | 本体・フェイスプレートがそれぞれ1個の有効ソリッド、相手部品との干渉0 | B-repチェック |
| wall | 最小肉厚 ≥ 1.5 mm | B-repで面の内向き法線方向にレイを飛ばして実測 |
| thread | 有効ねじ深さ ≥ 1.5d（M5で7.5 mm） | 図面のねじ深さと同じ値（止まり穴は下穴深さ−2 mm） |
| mass | 質量 ≤ `mass_target_g` | パラメータ |
| strength | von Mises（99.9パーセンタイル） ≤ 耐力/1.2（静的）、疲労強度/1.5（疲労） | 線形FEA（gmsh P2四面体 + scikit-fem）、コラム穴固定・ハンドル穴に荷重 |

- 荷重ケース（前方曲げ静的1600 N、横曲げ静的1000 N、前方曲げ疲労450 N）は ISO 4210-5 のステム試験を想定した**暫定値**。規格本文の荷重・腕長さ・回数を入れるまでレポートに provisional と出る
- 材料特性は便覧の代表値。量産前にJIS H 4140の規格最小値かミルシートの値に置き換える
- メッシュ寸法 h=2 mm（既定）と h=4 mm で前方曲げ応力の差は約4%（103 / 108 MPa）

## 鍛造品と鍛造型

ステムはアルミ熱間型鍛造 + 機械加工を想定し、`make_forging` が鍛造品（バリ抜き後・バリ付き）、上型・下型、型組立を STEP で出力する。

- 型の開閉方向は Y、見切り面はステムの中心面（Y = 0）。コラム穴・肉抜き穴・ねじ・すり割りは鍛造では作らず、加工で仕上げる。ハンドル穴は Y 方向なので、上下からのパンチで凹みを付け、中央に残したウェブをバリ抜き時に打ち抜く
- 鍛造品の形は外形 `stem.outer()` から自動で作る。Y方向の高さごとに断面を取り、取り代（1.5 mm）と勾配分だけ広げて、見切り面から抜き勾配（外側5°、パンチ7°）付きで押し出したものを重ねる。この作り方だと、どの壁も見切り面から離れる向きに勾配が付く
- 型のキャビティは鍛造品を熱収縮分だけ拡大したもの（A6061: 450 °C、型200 °C で約0.9 %）。バリ厚さは 0.015√(投影面積) から求め、ランド幅はその3倍、外側にバリ溜まり（ガター）を付ける
- 型材は SKD61（JIS G 4404）

チェック（`verify_forging`）はすべて B-rep 上で測る：

| ルール | 判定 |
|---|---|
| forging.contains_part / allowance | 完成品が鍛造品の内側にあり、表面からの取り代が 1.5 mm 以上 |
| forging.draft | 全ての壁が型の開閉方向に対して 5° 以上の勾配 |
| forging.undercut | 表面のどの点からも、型の抜け方向へ伸ばした線が鍛造品に再び当たらない |
| die.* | 上下型がそれぞれ1個の有効ソリッドで、熱間の鍛造品とも相手の型とも干渉しない |

レポートには質量（完成品・鍛造品・バリ込み）、歩留まり、プレス荷重の概算（10 × 変形抵抗 × バリランド込み投影面積）も出る。バリ寸法・変形抵抗・荷重係数は一般的な初期値なので、型を彫る前に鍛造シミュレーションか試打ちで合わせ込むこと。トリム型（バリ抜き型）は未作成。

## 2つ目の部品：アルミダイカスト製ブラケットとダイカスト金型

2つ目の部品は自動車用の取付ブラケット（ADC12、JIS H 5302）。`agent_cad/parts/bracket.py` の `BracketParams` で板・ボス・ハブ・リブの寸法、抜き勾配、加工取り代、材料、目標質量を変えられる。鋳造品（鋳放し）と完成品（ボス・ハブ上面の面削り、φ16 H7 のリーマ穴）を両方作る。

`make_diecast` が完成品・鋳造品・方案付き鋳造品（ランナー、ゲート、ビスケット、オーバーフロー）、可動型・固定型、押出しピン込みの型組立を STEP で出力する。

- コールドチャンバー式。見切り面はブラケットの裏面（Y = 0）。可動型（Y ≥ 0）にキャビティ・鋳抜きピン・方案を全部入れ、固定型は平らな面とスリーブ穴だけにした。製品は鋳抜きピンに縮み付くので可動型に残り、押出しピンで −Y 方向に押し出す
- 外壁とリブは 1.5°、鋳抜き穴は 1.0° の勾配。穴は見切り面側が一番細い。ハブ穴は上端で取り代がちょうど 0.8 mm になる
- キャビティは方案付き鋳造品を 0.55 %（ADC12 の鋳造収縮）拡大したもの
- ゲート断面は NADCA の充填時間式と目標ゲート速度（35 m/s）から求める。ランナー断面はゲートの 1.6 倍
- 押出しピン（φ6）は平らな面の上で、壁の付け根から 1.5 mm 以上離れた位置だけに置く。冷却穴（φ8）はピンとスリーブを避けて X 方向に通す
- 型材は SKD61

チェック（`verify_diecast`）はすべて B-rep 上で測る：

| ルール | 判定 |
|---|---|
| casting.contains_part / machining_stock | 完成品が鋳造品の内側にあり、加工面の取り代が 0.8 mm 以上 |
| casting.draft / undercut, shot.draft | 鋳造品と方案の全ての壁が +Y に開き（1.0° 以上）、可動型が抜ける |
| casting.min_wall | 実測の最小肉厚 ≥ 2.0 mm |
| die.* | 可動型・固定型がそれぞれ1個の有効ソリッドで、キャビティとも相手の型とも干渉しない |
| ejector.* | 各ピンの先端が全面で鋳造品の平面に当たり、キャビティにも型にも食い込まない。製品上に4本以上 |
| cooling.* | 冷却穴とキャビティ・スリーブの距離 ≥ 1.5 d、ピンとの距離 ≥ 4 mm |
| process.machine | 型締力（1.2 × 60 MPa × 方案込み投影面積）を満たす標準機がある |

レポートには質量（完成品・鋳造品・方案込み）、歩留まり、型締力と機械サイズ、充填時間、ゲート・ランナー断面、ゲート速度、型質量も出る。これらは一般的な初期値による**概算**なので、型を彫る前に湯流れ・凝固シミュレーションと試打ちで確認すること。ガス抜き（エアベント）とスライド型は未作成。

## 3つ目の部品：樹脂射出成形ハウジングと射出成形金型

3つ目は自動車用の電装ハウジング（箱型カバー、PA66-GF30）。`agent_cad/parts/housing.py` の `HousingParams` で外形・肉厚・角R・抜き勾配、リブ（十字）、ねじ止めボス4本（呼び径4の樹脂用タッピンねじ）、前面のコネクタ窓、材料、目標質量を変えられる。材料は `PA66-GF30` / `PA6-GF30` / `PBT-GF30` / `PP` から選べ、密度・成形収縮・成形条件が切り替わる（`agent_cad/process/molding.py` の `RESINS`、代表的なカタログ値）。

`make_molding` が製品、スプルー・ランナー・ゲート付きのショット、固定側・可動側・スライド、型組立（アンギュラピン、コアピン、突出しスリーブ・ピン、ショット込み）を STEP で出力し、JIS図面（PDF/DXF）も出す。

- 1個取り、コールドランナー、+X側面下端へのエッジゲート。見切り面は開口端面（Y = 0）。固定側（Y ≥ 0）が外面・スプルー・ランナー・ゲート、可動側（Y ≤ 0）のコアが内面・リブ・ボスを作る。製品はコアに縮み付いて可動側に残る
- 前面の窓は両方の型から見てアンダーカットなので、可動側のスライドで抜く。スライドは窓とその周りの外面を作り、固定側のアンギュラピン（18°）で −Z に引かれ、ロッキングヒール（20°）で射出圧を受ける
- 抜き勾配：外面・内面 1°、リブ・ボス・穴 0.5°、窓 1°（スライド方向）
- キャビティはショットを樹脂の成形収縮分（PA66-GF30 は 0.5 %）拡大したもの
- ゲート厚さは肉厚の 0.6 倍、幅はゲートのせん断速度（6Q/wh²）が樹脂の上限の半分になるように決める
- 突出し：床裏にピン（φ4）8本、ボス先端にスリーブ4本（中をコアピンが通る）、コールドスラグウェルの下にスプループラー
- 冷却：固定側は製品の上に X 方向の水管、可動側は Z 方向の水管からコアへバブラー4本
- 型材は SCM440（プレート）/ NAK80（キャビ・コア）を想定

チェック（`verify_molding`）はすべて B-rep 上で測る：

| ルール | 判定 |
|---|---|
| release.formed / draft / undercut | ショットの全表面について、すぐ外側の鋼材がどの型部品かをモデルから判定し、その部品の抜き方向（固定側 +Y、可動側とピン類 −Y、スライド −Z）に対して勾配 ≥ 0.5° で、抜き方向へ伸ばした線が製品に再び当たらない |
| release.draft_fixed / draft_slide / slide_forms_window | 外面 1°、窓 1° の勾配があり、窓はスライドが作っている |
| wall.min, design.* | 実測の最小肉厚 ≥ 1.0 mm、リブ根元 ≤ 0.6 × 肉厚、リブ高さ ≤ 3 × 肉厚、ボス外径 ≥ 2 × 穴径 |
| mould.* | 固定側・可動側・スライドがそれぞれ1個の有効ソリッドで、全部品（ピン類含む）がキャビティとも互いとも干渉しない |
| ejector.* | 各ピン・スリーブの先端が全面で製品の平面に当たる。床に4本以上、ボス4本全部にスリーブ |
| slide.* | アンギュラピンのストロークが窓の深さ＋2 mm 以上、後退したスライドが製品の突出し経路に当たらない、ヒール角 ≥ ピン角 + 2° |
| cooling.* | 水管とキャビティ ≥ 1.5 d、ピン類・アンギュラピン・スライドとの距離 ≥ 4 mm |
| process.* | 型締力から標準機（t）、ゲートせん断速度 ≤ 樹脂の上限、流動長/肉厚 ≤ 樹脂の目安、ランナー相当径 ≥ 肉厚 + 1.5 mm、製品が可動側に残る |

窓をスライドなしで固定側に作らせると release.undercut で検出されることもテストしている。レポートには質量（製品・ショット）、歩留まり、型締力と機械サイズ、冷却時間とサイクル、ゲート寸法とせん断速度、スライドのストロークと側圧、型質量も出る。数値は代表的な初期値による**概算**なので、型を彫る前に流動・保圧・そり解析（Moldflow 等）と試作型で確認すること。ガス抜き、ホットランナー、多数個取り、スライドの戻り止め・ガイドは未作成。

図面（A3、1:1、第三角法）：開口を上にした正面図（窓側）、開口側から見た図、ボス位置の断面 A-A。寸法は全部 B-rep から測って設計値と照合し、普通公差は JIS B 0405-c（粗級、樹脂公差は JIS K 7109 を参考に協議）とした。抜き勾配・PL・ゲート位置・突出しピン跡・材質表示（>PA66-GF30<）は注記。

## 4つ目の部品：ロードドロップハンドルと管の成形型

4つ目はステム（クランプ φ31.8）に付くロード用ドロップハンドル（A7075-T6）。`agent_cad/parts/handlebar.py` の `HandlebarParams` で幅（C-C）、リーチ、ドロップ、フレア、スイープ、クランプ径・クランプ部長さ、グリップ径、テーパー長、各部肉厚（クランプ・バテッド・グリップ）、曲げ半径、ドロップ直線長、材料、目標質量を変えられる。形状は曲げ表（直線 L0・曲げ B1・直線 L1・曲げ B2・直線 L2・曲げ B3・直線 L3）で決まり、幅・リーチ・ドロップを満たす直線長をニュートン法で解く。

工程（`tube_bending.py`、未経験の工法として管加工を選んだ）：

1. A7075-O の引抜き管 φ31.8 × 1.9 を素管長さに切断
2. 両端をロータリースエージングで φ23.8 に（テーパー部は空引きで肉が厚くなり、その先は端から入れる段付きマンドレルでバテッド 1.4 → グリップ 1.15 にする。内径は開口端へ向かって縮まないので、マンドレルが抜ける）
3. O 材のまま回転引き曲げ。片側ずつ中央から外へ B1 → B2 → B3。B1 の後のフード直線は短くてつかめないので、B2 は B1 の曲げに倣うクランプ型・インサートを使う。左側は逆勝手（両方向曲げ機）
4. 曲げしろを切り落とし、溶体化・焼入れ・時効（T6）を矯正治具の中で、検査ゲージで確認
5. バリ取り、ショット、アルマイト、クランプ部に目盛りのレーザーマーキング

治工具は曲げ型（溝 R40、インサートポケット付き）、直線用と B2 倣い用のクランプ型・インサート、プレッシャー型、ワイパー型（CAC703）、ボールマンドレル、スエージ型（2つ割）と段付きマンドレル。曲げの段取りごとに機械座標（曲げ型軸 Z′、接点 (0, −R, 0)）で作り、B2 の段取りを STEP 組立で出す。

チェック：

| ルール | 判定 |
|---|---|
| fit.* / wall.* / tops_hold_butting / process.mandrel_withdrawable | クランプ部長さ ≥ ステムのクランプ幅 + 余裕、規格クランプ径、曲げ外側の仕上がり肉厚 ≥ 0.85 mm、テーパー・バテッドの寸法関係 |
| strength.* | ISO 4210-5 相当の荷重（ドロップ下向き静荷重、フード前向き静荷重、フード／ドロップの同相・逆相疲労）。ソリッドFEA（右半分、P2 四面体、ステムクランプ部固定）の von Mises 99.9 パーセンタイルが静的は耐力/1.2、疲労は 1e5 回の疲労強度/1.25 以下。梁FEA（曲げ部の柔軟係数・SIF 付き）は参考 |
| swage.* | スエージのパス数（1パス最大の断面減少率から）、マンドレルが抜けること |
| bend.*.clamp_grip / trailing_straight | クランプのつかみ長さ ≥ 2 D、曲げ後ろの直管長 ≥ プレッシャー型長さ |
| bend.*.machine_hand / clear_table / clear_tube / die_relief | 振り回される既曲げ部が機械テーブル・キャリッジ・プレッシャー型・未曲げ部に当たらない向きがあり、曲げ型の逃げ ≤ 3 mm |
| bend.*.overbend / torque | O 材のスプリングバック（オーバーベンド ≤ 5°）、曲げトルク ≤ 600 N·m（32 mm 級 CNC 曲げ機） |
| tool.* | 各型が1個の有効ソリッドで、段取り状態の管にも互いにも干渉せず、マンドレルのボールが管内径に入る |

荷重は暫定（ISO 4210-5 の数値は規格本文で確認すること）、スプリングバックと曲げトルクは機械を合わせるための概算。曲げの肉厚変化・偏平は試し曲げと断面測定で確認する。

図面（A2、1:2、第三角法）：正面図、上からの断面 A-A、右側面図、クランプ部の取り外し断面 B-B（1:1）。曲げ表（L・R・A）、頂点座標表、肉厚表を付け、クランプ径 φ31.8 h10・グリップ径 φ23.8 h11、クランプ面 Ra 1.6。

## 締結計算書

`python -m scripts.fastener_report` → `out/fastener/締結計算書.pdf` と継手ごとの JSON。VDI 2230 Part 1 の簡易計算法と JIS B 1083 のトルク係数式で、締付トルクの範囲と摩擦係数のばらつき（μ 0.10〜0.16）から締付軸力の最小・最大を出し、次を確認する。形状は部品パラメータから読むので、寸法・材料を変えると再計算される。

| 判定 | 内容 |
|---|---|
| 締付時ボルト応力 | F_M,max での相当応力 ≤ 0.9 Rp0.2 |
| 使用時ボルト応力 | 作用荷重を加えた相当応力（ねじりは半分に緩和） ≤ Rp0.2 |
| 残留締付力 | F_M,min − なじみ損失 − (1 − Φn) F_A ≥ 継手に必要な締付力（滑り・ねじり試験トルク） |
| ボルト疲労 | 応力振幅 ≤ σ_ASV / 1.2 |
| 座面圧 | ≤ 0.9 Rm（被締結材） |
| 雌ねじせん断 | ねじ山のせん断力 ≥ ボルト破断力（ボルトが先に切れる） |

- ステム ピンチボルト（2×M5）：スリット付きクランプリング。リングのたわみをばね定数に、ステアラ接触面のなじみをスリットの閉じ量（2π倍）に換算。要求はステアラまわりのねじり試験トルク（暫定 40 N·m）
- ステム フェイスプレート（4×M5）：フェイスプレートの曲げたわみは FEA で求める（バー穴固定、座ぐり底に軸力）。要求はハンドル回転トルク（暫定試験 60 N·m × 1.2、ハンドル検証の同相フード疲労ピーク、静的フード荷重）。ハンドルバーの挟み部の周方向応力も確認
- ブラケット（4×M8 通しボルト）：ハブ荷重（仮定 2 kN）の横滑りとモーメントによる軸力。推奨締付トルクを算出（図面未記載）
- ハウジング（樹脂用タッピンねじ）：下穴・ボス・ねじ込み長をねじメーカーの設計ガイドの目安と比較。締付トルクは成形品で実測して決める
- 図面のトルク注記は `fastener_check.TORQUE_SPEC` から生成し、計算と図面が同じ値を使う。出図ビルドはステム本体図の報告に締結計算の結果を記録する

## メッシュ収束解析

`python -m scripts.mesh_study` → `out/mesh/メッシュ収束解析報告書.pdf`、収束グラフ、JSON。強度判定の固体 FEA（ステム本体、ハンドルバー右半分）を、全体寸法と曲率分割を √2 ずつ同時に細かくした 4 段階（本番メッシュの 2 段粗い〜1 段細かい）で解き、細かい 3 段から Richardson 外挿（Celik ほか 2008 の手順）で要素寸法 0 の値と GCI を求める。判定に使う値（最大変位、von Mises 99.9% 値）が本番メッシュで外挿値の 5 % 以内なら合格。各段のメッシュ品質（形状品質 q、最小二面角、縦横比）も出す。剛体支持の角部の最大値は特異点で細分化とともに増え続けるため判定に使わない。大きいメッシュは AMG 前処理付き CG で解く（`fea/static.py` `solve_cases(..., solver="amg")`、`pyamg`）。

## 提出図フロー（出図）

全部品と型の図面を固定の図番で管理し、自動検図とレビュアーの承認を通った版だけを「出図」にする。

```sh
python -m scripts.release                     # 台帳の全図面を生成・検図し、提出パッケージを out/release/ に出力
python -m scripts.release --write-history     # 新しい初版・未承認版の更新を release/history.json に記録
python -m scripts.release approve AC-1101 --by <氏名>   # 承認（人だけが行う。--all で全図面）
python -m scripts.release revise AC-1101 "ハブ穴径変更"  # 出図済み図面の次の改訂を起こす
```

- 図番台帳 `release/registry.json`：製品 AC-1xxx、型 AC-5xxx。図番は固定で、内容の変更は改訂記号（初版「-」、以降 A, B, …、I と O は使わない）で表す
- 形状指紋：図面の内容（寸法文字・公差・注記・表題欄・必要形状・粗さ・用紙）と B-rep（体積・表面積・外形）のハッシュ。署名欄と日付は含まない。承認済みの版と指紋が違えば改訂が必要（出図前チェックで不合格）
- 表題欄：改訂・状態・作成・検図・承認（氏名と日付）の欄と、直近2版の改訂欄。状態は「検図済 (未承認)」「出図」「検図不合格」。承認欄はレビュアーの承認記録（`release/history.json`）がその指紋と一致するときだけ埋まる
- 出図前チェック（すべて合格で検図済）：図面チェック（寸法と設計値の一致、はめあい、表題欄、レイアウト）、STEP受け渡しチェック、PMI の読み戻し、部品・型の設計/工程チェック、改訂の整合。型の図面は対応する製品図の図番と現行改訂を注記するので、製品が改訂されると型の指紋も変わり改訂が必要になる
- 3D図面：STEP AP242 にセマンティック PMI（直径・半径・平行2面間・軸間距離と公差）を、測った面に結び付けて書き込む。勾配付きの壁を断面で測った寸法（根元寸法など）は結び付ける面がないので 2D のみとし、レポートの `pmi.not_linked` に出す
- 型の2D：部品図は外形寸法・型合わせ面図・断面 A-A・穴表（冷却穴・ピン穴などを B-rep から数えて設計と照合）・材料・硬さ。キャビティ・コア形状と穴位置は3Dデータによる（CAM加工前提）。組立図は部品欄付き
- ハンドルバー（AC-1301）と管の成形型（AC-5401 曲げ型組立 B2 段取り、AC-5402〜5409 曲げ型・クランプ型/インサート（直線・B2 倣い）・プレッシャー型・ワイパー型・ボールマンドレル、AC-5411/5412 スエージ型・マンドレル）を台帳に追加。型部品は各自の図面座標（外形を軸に合わせ、上面 Y = 0）で描く
- ブラケット（AC-1101）の部品図を追加：鋳放し部 JIS B 0403 CT6、加工部 JIS B 0405-m、ハブ穴 φ16 H7 と裏面基準の直角度

提出パッケージ（`out/release/`）：`<図番>[_<改訂>].pdf / .dxf / .step / _report.json`、`図面一覧表.pdf`、`drawing_list.csv`、`変更履歴.md`、`manifest.json`（全ファイルの SHA-256、指紋、各ゲートの結果）。
